1. Smart Plant Watering System (ระบบรดน้ำต้นไม้อัจฉริยะ)
คำอธิบาย: โครงงานควบคุมการให้น้ำต้นไม้อัตโนมัติด้วยไมโครคอนโทรลเลอร์ (เช่น ESP32 หรือ Arduino) ร่วมกับเซ็นเซอร์วัดความชื้นในดิน พร้อมแสดงผลสถานะผ่านจอ OLED และแจ้งเตือนผ่านสมาร์ทโฟน

วัตถุประสงค์: เพื่อควบคุมความชื้นในดินให้เหมาะสมกับการเจริญเติบโตของพืช ประหยัดทรัพยากรน้ำ และประยุกต์ใช้เทคโนโลยี IoT ในงานเกษตรกรรม
